## Smartistiques 

Exploration des statistiques avec échantillonnage de boîtes de 
Smarties. Toutes les tailles sont acceptés et les données sont compilés dans 
un tableau pour faire des calculs statistiques. 

### Calculs

- Poids (g) moyen des Smarties 
- Variance et écart type selon le type de boîte de Smarties
- Entropie selon la matrice de communauté de Smarties. 

### Données 

Les données sont organisées en compte de chaque couleur, mais aussi par 
les informations des boîtes. 

Colonnes des couleurs
- boite_ID
- couleur
- nombre

Colonnes des boîtes : 
- boite_ID
- poids_g
- pesee_g
- date
- observateurs
